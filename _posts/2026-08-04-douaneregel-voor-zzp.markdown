Замовляєте матеріали чи товари з-за меж ЄС — з Китаю (Temu, AliExpress), з України, через Etsy чи будь-де ще? З 1 липня 2026 року правила стали жорсткішими і трохи дорожчими. Розбираємо, що саме змінилося і на що звернути увагу. <br/>
## Головні зміни <br/>
* **Нове мито**: €3 за кожну товарну позицію (тимчасово, до 2028 року) <br/>
* **Поріг €150**, до якого раніше мита не було, — **скасовано** <br/>
* Найближчим часом додасться ще й **окремий збір за обробку** (~€2) <br/>
* **Більше вимог до митних декларацій** <br/>
* **Зростає собівартість замовлень**, особливо дрібних і частих <br/>
## 1. Мито €3 за кожну товарну позицію <br/>
* Замовляєте шампунь + фарбу + кондиціонер — це 3 різні товарні позиції → €9 мита. <br/>
* Замовляєте 3 однакові шампуні — це 1 позиція → €3 мита. <br/>
**Важливий нюанс**: це не постійна ставка назавжди. Це тимчасовий спрощений тариф, який діє **з 1 липня 2026 до 1 липня 2028 року**. Після цього мито знову рахуватимуть **за звичайними товарними кодами** — і воно може бути як більшим, так і меншим за €3, залежно від конкретного товару. <br/>
## 2. Поріг €150 скасовано <br/>
Раніше товари вартістю до €150 ввозили без мита. Тепер це звільнення прибрали. <br/>
## 3. Скоро додасться ще й окремий збір за обробку <br/>
ЄС готує окремий додатковий збір ("handling fee") приблизно €2 за товарну позицію, який компенсує митницям витрати на обробку зростаючого потоку дрібних посилок. Очікується, що він запрацює орієнтовно з листопада 2026 року. <br/>
## 4. Мито впливає на розрахунок ПДВ <br/>
За загальним митним принципом до бази для розрахунку імпортного ПДВ входить не лише вартість товару й доставки, а й сплачене мито. Тобто €3 (а згодом, можливо, і handling fee) імовірно теж потраплять у цю базу — а отже, і ПДВ, який нараховується зверху, трохи зросте. <br/>
**Важливо розрізняти**: ПДВ, сплачений при імпорті, можна повернути/відняти як звичайну voorbelasting — за умови, що є коректна фактура з БТВ-номером продавця. <br/>
А от саме мито €3 — це не ПДВ, і його повернути не можна. Це просто додаткова витрата. <br/>
## 5. Зростають вимоги до декларацій <br/>
Платформи й продавці тепер мають подавати точніші дані про кожен товар. На кожну посилку до €150 тепер потрібна окрема митна декларація, і мінімум три коди ідентифікації товару. <br/>
Для дрібних ZZP це на практиці означає: <br/>
* більше шансів на затримки на кордоні; <br/>
* більше можливих перевірок; <br/>
* більше випадків, коли митниця сама "розбиває" одну посилку на кілька позицій → відповідно більше мита. <br/>
## 6. Вплив на собівартість <br/>
* Кожне замовлення стає трохи дорожчим — навіть найдешевші дрібні речі. <br/>
* Часті дрібні замовлення стають менш вигідними — краще об'єднувати покупки в одне замовлення, коли це можливо. <br/>
* Разом мито + (згодом) handling fee + вищий ПДВ на цю суму — сукупний ефект може бути суттєвим, особливо при регулярних замовленнях витратних матеріалів. <br/>

**Підсумок для ZZP**: якщо ви регулярно замовляєте матеріали з-за меж ЄС, варто вже зараз перерахувати реальну собівартість з урахуванням нового мита — і стежити за новинами щодо handling fee, який запрацює найближчими місяцями. І, як завжди, зберігайте всі документи по кожному замовленню — за нових правил це стає ще важливішим для коректного обліку. <br/>
